# Security Policy

bluepencil's deterministic analyses and browser playground run locally. Model-backed commands send selected text to the provider you configure only when you invoke them.

## Report a vulnerability

If you find a vulnerability, [report it privately through GitHub Security Advisories](https://github.com/writerslogic/bluepencil/security/advisories/new) rather than opening a public issue. Include the affected version, steps to reproduce, and the potential impact. Please avoid including unpublished manuscripts or credentials unless they are essential to reproduce the issue.

## Response and disclosure

We aim to acknowledge reports within a few days. We will investigate privately, share a remediation timeline with the reporter, and coordinate public disclosure after a fix or mitigation is ready.

Only the latest release receives security fixes.
