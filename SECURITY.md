# Security Policy

bluepencil's deterministic analyses and browser playground run locally. Model-backed commands send selected text to the provider you configure only when you invoke them.

If you find a vulnerability, [report it privately through GitHub Security Advisories](https://github.com/writerslogic/bluepencil/security/advisories/new) rather than opening a public issue. You can expect an acknowledgment within a few days.

Only the latest release receives security fixes.
