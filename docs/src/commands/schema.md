# schema

Prints the JSON Schema for a command's `--json` output.
Schemas use JSON Schema Draft 2020-12.

```sh
bluepencil schema count
```

Every command with structured `--json` output is covered: `adverbs`, `arc`, `cast`, `check`,
`cliches`, `config`, `continuity`, `count`, `dialogue`, `echoes`, `facts`, `filter`, `freq`,
`hedges`, `histogram`, `nominal`, `outline`, `overused`, `passive`, `pov`, `progress`,
`readability`, `repeats`, `report`, `rhythm`, `scenes`, `speakers`, `starters`, `tags`,
`tense`, `tics`, `unique`, `voice`, and `wdiff`.
