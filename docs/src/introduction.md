# Find the lines worth revising

bluepencil is a local prose linter for fiction and long-form writing. It finds repeated words, distracting sentence patterns, style flags, and pacing changes, then points to the passage so you can decide what to keep.

**[Open the browser writing desk](../)** — paste a manuscript, explore inline observations, and chart its rhythm. Analysis runs locally in WebAssembly, without an account or upload. The [browser guide](browser.md) covers highlights, the chart, and the 16 MiB input limit.

For native writing-app formats and project workflows, [install the CLI](installation.md), open the [quick start](quickstart.md), or read the [input formats](formats.md). The deterministic commands run offline. Optional model-backed commands send text to the provider you configure when explicitly invoked.
